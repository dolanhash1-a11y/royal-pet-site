# Royal Pet — безкоштовний сайт

Відкрийте `index.html` у браузері, щоб переглянути сайт. Для змін відкрийте цей файл у безкоштовному редакторі [VS Code](https://code.visualstudio.com/).

## Що замінити перед публікацією

У `index.html` знайдіть і замініть:

- `Royal Pet` — назву студії;
- `м. Київ, вул. Прикладна, 10` — адресу;
- `+38 (000) 000-00-00` і `+380000000000` — телефон;
- `https://instagram.com` і `https://t.me` — посилання на ваші соцмережі;
- ціни та приклади відгуків.

Фото тимчасово взяті з Unsplash. Замість них варто додати ваші власні фото.

## Як приймати заявки безкоштовно

Найпростіше створити Google Form з тими самими запитаннями. У самій формі натисніть вкладку **Відповіді** → значок Google Sheets, щоб усі заявки автоматично потрапляли в таблицю.

Для цього сайту найпростіший варіант: у Google Form натисніть **Надіслати** → значок `<>` → скопіюйте HTML-код iframe. В `index.html` замініть весь блок від `<form id="booking-form" class="booking-form">` до `</form>` на скопійований iframe. Тоді заявки будуть надходити в Google Form.

## Як безкоштовно опублікувати на GitHub Pages

1. Створіть обліковий запис на [GitHub](https://github.com/).
2. Натисніть **New repository**, введіть назву `royal-pet` і створіть репозиторій.
3. Натисніть **Add file → Upload files** і завантажте `index.html`, `style.css` та `script.js` з цієї папки.
4. Відкрийте **Settings → Pages**. У блоці *Build and deployment* виберіть **Deploy from a branch**, гілку `main` і папку `/(root)`, натисніть **Save**.
5. За кілька хвилин GitHub покаже адресу сайту на кшталт `https://ваш-логін.github.io/royal-pet/`.

GitHub Pages безкоштовний. Власна коротка адреса (домен) не обов’язкова і купується окремо, якщо знадобиться.
